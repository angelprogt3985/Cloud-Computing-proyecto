# Pasos de despliegue

1. Crear proyecto en GCP y activar facturacion
2. Habilitar APIs necesarias (Cloud Run, Cloud SQL Admin, Storage, Agent Platform API)
3. Levantar Cloud SQL y definir esquema
4. Desplegar la API a Cloud Run
5. Subir assets estaticos a Cloud Storage y activar Cloud CDN
6. Configurar IAM con roles personalizados
7. Automatizar todo con GitHub Actions
