# infra/

Infraestructura como Codigo (Terraform) - para el bonus de hasta 5 puntos extra.
Aqui va la definicion de:
- Cloud Run (API)
- Cloud SQL (base de datos)
- Cloud Storage + Cloud CDN (assets estaticos)
- IAM (roles personalizados documentados)

## Como aplicar (borrador)
1. gcloud auth application-default login
2. terraform init
3. terraform plan
4. terraform apply
