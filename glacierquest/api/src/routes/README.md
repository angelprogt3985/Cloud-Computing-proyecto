# routes/

Endpoints REST de la API. Sugeridos:
- position.js  -> POST /position (actualiza posicion del jugador, usado por el polling del cliente)
- chat.js      -> GET/POST /chat (mensajes del chat compartido)
- battle.js    -> POST /battle (resuelve Attack/Run contra el NPC)
- inventory.js -> GET /inventory (items recolectados por el jugador)
